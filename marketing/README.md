This folder is the Landing Page Manager guide pack and related marketing source. The guide is also the wording source for the public website guide, GitHub Wiki, and any PDF export. `marketing/` is excluded from the installable plugin ZIP.

## Guide pack

- `pack.json` — Product name, slug, version, and the single legacy path.
- `PROMPT.md` — Import instructions for the Duppins Technology knowledge base.
- `guide/` — Home, install, contextual Help, WordPress Dashboard widgets, Landing Pages Dashboard, client and keyword lists/editors, landing-page list/editor, Analytics, Settings tabs, and deactivation.
- `guide/order.txt` — Article order; Home is first and PROMPT is not listed.
- `guide/fragments.json` — WordPress screen and Settings-tab guide fragments.
- `guide/_Sidebar.md` — GitHub Wiki sidebar.
- `screenshots/admin/manifest.json` — Fragment-keyed screenshot callout text.
- `screenshots/admin/` — wp-admin configuration screens with numbered red callouts.
- `screenshots/examples/` — Published front-end pages only; no public example screenshot is included.

The plugin has no published plan price or checkout URL. Product support is available at support@duppinstech.com or (240) 397-8221; the Pro early-access link is separate.
