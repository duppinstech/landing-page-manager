The directory listing needs screenshots of the wp-admin screens where an owner configures the plugin, not only published front-end pages.

1. `install.jpg` — Plugins → Add Plugin: choose the plugin ZIP before installing it.
2. `clients.jpg` — Landing Pages → Clients: enter a client name before adding its details.
3. `client-editor.jpg` — Client editor: review the name and slug before setting brand and contact fields.
4. `keywords.jpg` — Landing Pages → Keywords: name and add a keyword for page organization.
5. `templates.jpg` — Settings → Templates: choose the site-wide template.
6. `api-keys.jpg` — Settings → API Keys: configure optional map or branding integrations.
7. `landing-pages.jpg` — Landing Pages list: start a new landing page.
8. `landing-page-editor.jpg` — Landing Page editor: assign a client and complete the page fields.

`screenshots/examples/` is for published results, not setup screens.
