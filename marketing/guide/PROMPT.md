# Website guide publishing prompt

Publish one guide page at the public guide URL: https://duppinstech.com/landing-page-manager/guide/ . Add an HTML element id for every stable fragment in `guide/fragments.json`; the plugin's Help button opens this public URL plus the matching hash.

Use the markdown files in `guide/` as the words. Follow `guide/order.txt` for reading/PDF order, skip `Home.md` when building a PDF, and place each screenshot beside the steps that describe it. Preserve image paths such as `../screenshots/admin/file.jpg` in the markdown source and resolve them to the published screenshot assets.

Do not add screens, prices, buttons, features, or checkout links that these files do not name. The published support contact is support@duppinstech.com and (240) 397-8221. No public plan price or checkout URL is published; do not invent any. The plugin's current Pro link is for early access, not checkout.
