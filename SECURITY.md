# Security Policy

## Supported versions
Only the latest release receives security fixes.

| Version | Supported |
|---|---|
| 1.0.x (latest) | ✅ |
| older | ❌ |

## Reporting a vulnerability
**Do not open a public issue.** Instead, either:
- use GitHub's private advisory form ("Report a vulnerability" on the Security tab), or
- contact Duppins Technology through https://duppinstech.com.

Include the affected version, steps to reproduce, and the impact. We aim to
acknowledge reports within 3 business days and to ship a fix or mitigation
within 30 days, depending on severity.

## Scope
Everything in this repository: admin and AJAX/REST handlers, template upload,
subdomain rewrites, the GitHub updater, and the bundled templates.
The Pro add-on is maintained in a separate repository.
